Daily Signal — 2026-11-24

Breaking News

Z.ai releases GLM-5.4, its first loop transformer model – the Chinese lab published an overview of GLM-5.4 and Simon Willison wrote a summary on Nov 23. The headline innovation is a looped transformer architecture: a group of weight-shared layers runs multiple iterations per token, refining hidden states. This is the same trick used by Thinking Machines Lab’s Inkling 2 Mini (see Headlines) and promises better capability-per-parameter for on‑prem inference. GLM‑5.4 is aimed at coding and agentic tasks, not just chat. How to make the most of it: (1) Watch for a GGUF conversion and test it in llama.cpp once it lands – looped layers may change memory-access patterns compared to standard MoE models; (2) benchmark it against Qwen3.8 27B and similar open‑weights on your own agent tasks, because paper claims may not survive your eval; (3) if you’re running on budget GPUs, pay attention to active-parameter counts – looped transformers with low active parameters could be a sweet spot for 12‑16 GB cards.

Headlines

  • Inkling 2 Mini release – Thinking Machines Lab shipped a 26B MoE with 3B active parameters that matches Qwen3.8 27B on paper, using a looped transformer (12 of 24 layers run three times per token). The Codacus video tests it on real hardware and reports it actually runs on budget GPUs. This is the first serious open‑weight implementation of the looped‑transformer idea, so keep an eye on GGUF availability.

  • llama.cpp 1.0.0 – The local inference engine hit a major milestone with stable API, FP8 KV cache, MoE expert cache, and server hardening. Full details are worth reading if you haven’t upgraded in a while – the FP8 KV cache alone can cut memory requirements significantly.

  • Ollama and vLLM releases – Ollama’s late‑November cadence (v0.40.14–v0.40.16) adds new model support and changes OpenAI API default parameters; vLLM 0.33.0 moves to CUDA 13.0‑only, drops Medusa/MLP speculative decoders, and adds new models. Both are summarized in the same local inference news roundup.

  • Together AI adds DeepSeek-V4.1-Flash-1017-fast – the fast serving tier now supports 1,000,000 context length, FP8 quantization, function calling, and structured outputs. See the changelog for exact availability.

  • “LLM agents work for their parent companies, not for you” – a thoughtful essay argues that agent oriented around cloud providers will naturally favor those providers’ services and data. Worth reading before you commit to any vendor‑locked agent stack.

  • How should an LLM see a computer? – Greptile’s blog compares accessibility‑tree‑based perception with pixel-based for computer‑use agents, a decision that directly affects reliability and latency in your own agent projects.
